# Public toot viewer

マストドンの公開タイムラインをみるやつ。inspired by https://junk.azyobuzi.net/mastodonptl/

https://m6n-view.hnle.tk/

## Build Setup

Requires Node.js 20.19+ / 22.12+ and [pnpm](https://pnpm.io/) (enable via `corepack enable`).

``` bash
# install dependencies
pnpm install

# serve with hot reload at localhost:5173
pnpm dev

# build for production with minification
pnpm build

# run tests
pnpm test

# lint (oxlint) and type check (vue-tsc)
pnpm lint
pnpm typecheck
```
